## 🧪 Research & Projects

### [🔬 FUNASP - Functional Answer Set Programming](https://github.com/krr-uno-fasp)

Research and development of **FUNASP**, an extension of Answer Set Programming that introduces functional syntax and higher-level abstractions while preserving compatibility with Clingo.

My work involves designing and implementing functional assignments, partial functions, parser extensions, and AST transformation pipelines. The Python-based compiler translates functional programs into standard ASP, handles nested functions and aggregates, and reconstructs functional answer sets from solver output.

**Technologies:** `Python` `Clingo` `ASP` `Tree-sitter` `AST Transformations` `Compiler Design`

---

### [🧠 NeurASP - Neuro-Symbolic AI](https://github.com/krr-uno/neurasp-splitting-system)

Research on integrating **neural networks with Answer Set Programming** to enable learning from symbolic rules and constraints.

The project explores compiling symbolic reasoning into reusable, differentiable PyTorch operations, allowing neural networks to learn from task-level observations. It also investigates **program splitting and intermediate-state reuse** to reduce redundant computation and improve scalability.

Research examples include MNIST addition, digit membership, and card arithmetic, with benchmarking against alternative neural-symbolic approaches.

**Technologies:** `Python` `PyTorch` `Clingo` `ASP` `Neural-Symbolic Learning`

### [🤖 Agentic Harness - Multi-Agent Software Development](https://github.com/ravip5921/Agentic_Harness)

A Python-based **agentic software development framework** that uses LangGraph and LLM-powered agents to automate and coordinate software development tasks, from requirement analysis to implementation, testing, and release preparation.

The system consists of four specialized stages:

| Stage | Responsibility |
|---|---|
| 🔍 Research | Investigates requirements and generates engineering specifications |
| 💻 Developer | Implements and stages code based on specifications |
| 🧪 QA | Runs tests, validates requirements, and provides feedback for revisions |
| 🚀 Release | Prepares validated artifacts for human review and approval |

The framework supports iterative QA-driven development, structured artifacts, isolated testing, and human-in-the-loop releases.

**Technologies:** `Python` `LangGraph` `Pydantic` `LLMs` `Docker` `pytest`
